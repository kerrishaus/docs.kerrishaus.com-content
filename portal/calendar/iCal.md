# The Portal supports the iCal standard
The [iCal](https://en.wikipedia.org/wiki/ICalendar) standard helps organise calendar data in a way that is useable by many different systems, which may not be related to one another. The Portal calendar system supports this standard, allowing you to see your Portal events in other applications. As of writing, the Portal only supports *exporting* calendars. It cannot import and display Calendar data from other systems.

# Using your calendar in an iCal compatible application
> [!CAUTION]
> Only the owner of a calendar can generate an iCal link for that calendar. If a calendar you wish to use does not have an iCal link, request that the owner generates one.

1. From the main Calendar page, select one of your Calendars and open its settings page.
2. From the calendar's settings page, click `Sharing Settings`.
3. Copy the shareable iCal link.

For instructions on how to import a Portal calendar into another application, refer that specific application's instructions.
