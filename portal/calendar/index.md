# Calendar
A calendar on the Portal is a representation of a group of events. At it's simplest, it simply contains a list of events and who can see them.

A calendar may be shared with other users so that they have access to the events on that calendar. Users with which a calendar has been shared will be able to view, modify, and delete any events associated with that calendar. They will also be able to update details of the 
calendar itself, such as name and colour. Users with which a calendar has been shared do not have the ability to delete the calendar.

!> Only the owner of a calendar can delete the calendar or change sharing settings. However, if an iCal link has been generated for a particular calendar, anyone with access to the calendar will be able to use it.

# Sharing Events
Events on the calendar can be shared with individual users via "assignees."

!> Only the owner of an event can delete it, however any user with access to an event can change the properties of the event.
