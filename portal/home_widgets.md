# Home page widgets
The home page on the Portal can be customised with various widgets and placements. Some widgets can have child widgets.

## Control Center
Displays information about the user including their avatar, name, title, and a brief status message generated based on the user's information throughout the Portal. Also shows any unread notifications.

## Feed
Shows Portal announcements and RSS/Atom feeds from user specified sources in a newest to oldest top to bottom layout. If a feed does not provide an author, the domain name of the feed will be shown instead. New feeds can be managed from a [user's feeds settings page](https://portal.kerrishaus.com/users/me/settings/feeds).

## Horizontal Layout Box
Used to contain other widgets in a horizontal layout.

## Page List
Displays lists of pages that a user has access to. This widget shows pages that a user has permission to use. It can be set to be "inclusive," which will show only pages that belong to a particular category, or "exclusive," which shows all pages in categories outside of categories which are provided.

## Search Widget
A quick searchbox for Google.

## Timer Widget
A single timer which a user can set.

## Vertical Layout Box
Used to contain other widgets in a vertical layout.

## Weather
Shows weather for a user's location.
